Data Protection

Encryption at every layer.

🔒
Data at Rest
All agent logs, hash records, and user data are encrypted with AES-256-GCM using Fernet (Python cryptography library). The encryption key is machine-bound and never transmitted.
🔐
Data in Transit
All C2 communication uses HTTPS over TLS 1.3. Agent heartbeats and alert payloads are encrypted end-to-end. API keys are never logged or exposed in error responses.
🗄
Database Security
PostgreSQL on Neon with row-level security. Passwords hashed with bcrypt (cost factor 12). Session tokens are cryptographically random 256-bit values.
📋
Audit Logging
Every authentication event, license operation, and admin action is written to a tamper-evident HMAC-signed audit log. Logs rotate automatically and are retained for 90 days.
